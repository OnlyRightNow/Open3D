## Motivation and Context

`Octree.to_voxel_grid()` and `VoxelGrid.create_from_octree()` always return a grid with 1 voxel and `voxel_size == 0`. Several users have reported this since 2021.

## Description

**Plan summary**
- Goal: one voxel per octree color leaf, with `voxel_size` equal to the leaf size.
- Requirements: `voxel_size` is the smallest leaf size and never 0 for a non-empty octree; origin stays the octree origin; no API change.
- Test method: new C++ test `Octree.EightCubesToVoxelGrid`, new Python test `test_octree_to_voxel_grid_voxel_size`, plus the triage repro script.
- Risk: a `voxel_size` preset on the target grid before `create_from_octree` is now overwritten by the leaf size. Presetting it was the only workaround and still gives the same result when it equals the leaf size.

**Root cause**
`cpp/open3d/geometry/VoxelGrid.cpp`, `VoxelGrid::CreateFromOctree`: `voxel_size_ = std::min(voxel_size_, leaf size)` starts from the default `voxel_size_` of 0, so it stays 0 and every index is computed by dividing by 0.

**Change**
- Start the minimum from `octree.size_`, which bounds every node size (1 line plus a comment).
- Doxygen and both Python docstrings now say each leaf becomes one voxel of the smallest leaf size.
